## What This Folder Is
This is your library. Everything in [[WIKI/personal/]] is about *you*. Everything here is about *the world*.

Drop papers, AI research, energy reports, articles, long-form notes here. One file per topic area. Link them to personal pages when relevant.

## Folders
- [[climate-and-energy/_index]] — Energy transition, climate finance, CCUS, clean tech, markets
- [[ai-and-technology/_index]] — AI automation, tools, ML research, tech landscape
- [[finance-and-economics/_index]] — Macro, investing, financial modelling, impact finance

## How to Add a New Note
1. Create `WIKI/knowledge/[topic-area]/[slug].md`
2. Add frontmatter: title, tags, sources (link to RAW file), date_read, key_claims
3. Add wikilinks to relevant personal pages (e.g., if it's relevant to career, link [[career-principles]])
4. Update this index
