# Personal Productivity System - Consolidated Notes

## Core System Architecture (Notion PPV)

### The Four Pillars Framework

**Pillars & Support** - Life Foundations

- Databases: Pillars (life domains), Habits & Routines, Fitness
- Page: Mindset & Identity Sculpturing
- Purpose: Define and maintain fundamental life areas

**Pipelines** - Goal Execution

- Databases: Value Goals, Goal Outcomes, Projects, Content Creation (optional)
- Purpose: Bridge aspirations to concrete work

**Vaults** - Knowledge Repository

- Databases: Notes & Ideas, Books, Media, Knowledge Base, Contacts (optional)
- Purpose: Centralized reference and learning system

**Journals & Reviews** - Reflection System

- Databases: Daily Tracking, Weekly/Monthly/Quarterly/Annual Reviews, Accomplishments, Feedback
- Purpose: Multi-horizon reflection and course correction

## Processing Workflow (GTD Logic)

### Inbox Processing Decision Tree

**First Filter: Is it Actionable?**

- NO → Reference / Trash / Someday-Maybe
- YES → Continue to next questions

**Action Questions (in sequence):**

1. **ASAP?** → Do immediately
1. **Less than 2 minutes?** → Do it now
1. **Multi-step?** → Break into actionable steps (becomes Project)
1. **For a project?** → Add to Project file
1. **Can delegate?** → Waiting list
1. **Is it a meeting?** → Agenda
1. **Trip required?** → Errands
1. **Specific time?** → Calendar
1. **Default** → Next Actions (with Tickler for future timing)

### Context Dimensions for Tasks

Tasks should be tagged with relevant contexts:

- **Who?** - People involved
- **Where?** - Location requirements
- **When?** - Time constraints
