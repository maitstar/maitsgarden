# Setting Up My Mac

## Initial Setup
1. Add fingerprint twice
2. Switch off True Tone
3. Show scroll bars always
4. Install Superwhispr

## File System Rules

**Downloads Folder (The "Inbox"):** Never store anything here. Treat it like a physical mailbox. Open the mail, file it where it belongs, toss the envelope. Goal: 0 files in Downloads at end of every day.

**Documents Folder (The "Library"):** Your permanent records. Structure:
- Career: Master Resumes, Columbia degree scans, work samples
- Admin: Passport scans, tax info, medical records
- Learning: Coursework, eBooks, development research

**Desktop (The "Workbench"):** Only what you're actively working on right now. Once you hit "Send," move it to Documents and clear the Desktop. Use **Stacks** (right-click Desktop → Use Stacks) to auto-group active files.

**iCloud Drive (The "Sync Engine"):** Don't use the iCloud Drive tab directly. Just use your Documents folder. iCloud is the invisible truck that carries your Documents folder to your iPhone.

## Search-First Naming Rule
Stop organizing by *where* you put things. Start organizing by *what* they're named. Spotlight (Cmd + Space) is your primary tool.

Format: `Date_Subject_Entity.ext`
- Resume: `2026-03_Resume_Maitreyi_Blackrock.pdf`
- Transcript: `2024_Transcript_Columbia_Official.pdf`
- Training: `2026-03_Training_Log.pdf`
